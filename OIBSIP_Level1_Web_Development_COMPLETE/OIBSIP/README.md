# OIBSIP — Web Development & Designing, Level 1
Included projects: Landing Page (HTML/CSS), Personal Portfolio (HTML/CSS), Temperature Converter (HTML/CSS/JavaScript).

## Run
Extract the ZIP, open the `OIBSIP` folder in VS Code, then open each project's `index.html` in a browser. Each project folder includes a README with instructions.

## Before submission
Test on desktop and mobile, personalize portfolio details and links, take screenshots of the working pages, upload to a public GitHub repository named exactly `OIBSIP`, and follow the internship's official demo-video and submission instructions. These are starter implementations; test and review them before submitting.
